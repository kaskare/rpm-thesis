Value-axis model: a convolution along the attribute values (I-RAVEN-X 3×10, values 0–49)¶

Every attribute value is a constant of the template (v0 … v50), and a panel's attribute is a fact x(P, A, v17). Background facts give the values their structure: off(U, V, k) for V = U + k (k = −2…2) and plus(U, W, V) for U + W = V. No rule names a value, so every rule is the same at every value, the way a CNN is the same at every pixel (notes §27, FINDINGS items 25–27).

  • The kernel stamps five learned codes around each panel's value: h(P, A, V) means "V is k above P's value".
  • Comparing panels at every value and summing over the values gives a code of their offset, not their values.
  • The answer is scored at every value by the same two layers (a 1×1 convolution), from the rule the context points to, the offset from the last panel, the value counts per row, and the exact sums.

It is closer to the symbolic template than to the facet model: the primitives (sums, counts, offsets of ±2) are given, and it learns which rule applies and how to combine them. Weights: experiments/valaxis_n10_m50_plus (6000 training puzzles, the epoch picked on puzzles 6000–6299); everything below is on unseen puzzles 6300+.

Sections: 1. a puzzle · 2. the template · 3. the graph of this puzzle · 4. the kernel · 5. generating the answer · 6. the value symmetry · 7. all runs.

3. The graph of this puzzle¶

PyNeuraLogic grounds the template on the puzzle's facts into a network (FV.ground_graph); the pictures draw that network for one attribute, with every ground atom placed by its own arguments. Nothing is drawn that the grounding does not contain.

  • Lanes are the 29 context panels, (row, column) and the panel's value. Black: the panel's value x. Purple: the kernel atoms h, only within ±2 of the value. Lilac, between two lanes: the comparison pv of neighbouring panels at each value.
  • Green squares on the right are value-free: a pair's offset code pd (one per neighbouring pair), each row's descriptor rd, distinct values nd, overlap ov, the plus / minus checks, and the context ctx.
  • Orange paths are the exact running sums along each row (acc for plus, accm for minus). They exist only while the sum stays within 0–50.
  • Blue dots under each row: how many panels of that row hold each value.
  • Output lane: one node per value (the scoring layers o, o2, s merged), fed by the context (the light fan), the last panel's kernel atoms (purple), the counts and the sums. The bars are the trained model's probabilities.

Colour (Arithmetic, plus form): the row-3 sum reaches 38, and the output follows it.

4. The kernel¶

Five learned codes of 32 numbers, one per offset −2…+2 (160 weights). Each panel has one value, so the convolution just stamps them around it. Their job is to tell the offsets apart; the layers that read them do the rest. How alike two codes are varies between runs: here −0.47 to 0.5 (the codes of −1 and +1 are the most alike), in the 600-puzzle run −0.38 to 0.07, close to random 32-number vectors.

6. The value symmetry¶

Moving every value of an attribute by k moves the output by k: no rule names a value, so by the theorem of notes §21.2 the network of the shifted puzzle is the same network, renamed. The plus relation is the exception: (u+k) + (w+k) ≠ (u+w) + k, so where a shift changes a sum, the output may change too. Below, type values of the puzzles whose type is not Arithmetic are moved by +3, with the trained model and with the model trained without plus.

The same weights also run on a value range never seen in training: no weight belongs to a value.

7. All runs (1000 unseen puzzles each, from the runs' best.json)¶

  • plus*: the model above at 6000 / 600 / 100 training puzzles.
  • noplus: without the plus relation. The convolution keeps Constant, Progression and Distribute; Arithmetic falls to chance-like levels: a kernel of ±2 cannot add.
  • pervalue*: the ablation of the value symmetry. Every rule with weights is written once per value, with its own weights (335k weights); the primitives are the same. Without sharing across values, each value's scoring layers learn from the few puzzles whose answer is near that value.

For comparison, the facet model with column roles: 94.1% matched, 29.0% exact, with 288k weights and 6000 puzzles.

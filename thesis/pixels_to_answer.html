From pixels to answer: ResNet-18 → PyNeuraLogic¶

One I-RAVEN puzzle, followed from its 16 raw panel images to a predicted answer, then a quick accuracy check over a sample. Nothing here reads the XML labels on the way to the answer; the XML is used only to show where perception was right or wrong.

stage what from
perception ResNet-18 turns each panel image into a 512-d vector, matched against a frozen codebook of 6622 attribute vectors log/universal_frontend_correct_proportional_mean3 (trained on RAVEN)
decoding per position, the best-matching attribute combination; the object exists if its cosine > 0.23 pixel_pipeline.panels_from_preds
encoding objects laid into the 16 panels × 9 slots graph train_all_constellations.encode_puzzle
reasoning the trained PyNeuraLogic model scores the 8 candidates experiments/max_data_L2 (best checkpoint)

Every step calls the project's own code, so this is exactly the pipeline behind the 63.96% pixel result in thesis/PYNEURALOGIC_NOTES.md §11, run on CPU in one kernel.

Which puzzles: validation puzzles from index 300 on. Training never sees the validation split, and checkpoint selection uses only its first 300 puzzles per constellation, so these are unseen and do not touch the test split, which is kept for one final evaluation.

Run with the pynl kernel on a compute node (an interactive srun session, or the batch command at the end), CPU only, about 2 minutes end to end. Not on the login node: it kills CPU-heavy Jupyter kernels (SIGKILL). A bare 16-thread matrix-multiply kernel is killed there, while the same work as a plain script is not.

1. The puzzle, as pixels¶

A puzzle is 16 grayscale images of 160×160: eight context panels forming a 3×3 matrix with the last cell missing, and eight candidate answers.

In [2]:
def show_puzzle(images, marks=None, s=104, gap=6):
    # 3x3 context (missing cell shown as '?') next to the 8 candidates; marks = {candidate: (rgb, label)}
    marks = marks or {}
    W, H = 3 * s + 4 * gap + 40 + 4 * s + 5 * gap, max(3 * s + 4 * gap, 2 * (s + 18) + 3 * gap) + 22
    canvas = Image.new("RGB", (W, H), (236, 238, 242))
    d = ImageDraw.Draw(canvas)
    d.text((gap, 4), "context", fill=(60, 64, 72))
    for p in range(9):
        x, y = gap + (p % 3) * (s + gap), 22 + (p // 3) * (s + gap)
        if p < 8:
            canvas.paste(Image.fromarray(images[p]).resize((s, s)).convert("RGB"), (x, y))
        else:
            d.rectangle([x, y, x + s, y + s], outline=(90, 94, 102), width=2)
            d.text((x + s // 2 - 3, y + s // 2 - 6), "?", fill=(90, 94, 102))
    x0 = 3 * s + 4 * gap + 40
    d.text((x0, 4), "candidates", fill=(60, 64, 72))
    for c in range(8):
        x, y = x0 + (c % 4) * (s + gap), 22 + (c // 4) * (s + 18 + gap)
        canvas.paste(Image.fromarray(images[8 + c]).resize((s, s)).convert("RGB"), (x, y))
        rgb, label = marks.get(c, ((60, 64, 72), ""))
        if c in marks:
            d.rectangle([x - 3, y - 3, x + s + 2, y + s + 2], outline=rgb, width=4)
        d.text((x, y + s + 3), f"{c} {label}", fill=rgb)
    display(canvas)

2. Perception: what the ResNet sees¶

Each panel goes through ResNet-18 to a 512-d vector, which is compared by cosine similarity with every row of the frozen codebook: 22 positions × (300 attribute combinations + 1 "object here" row). For each position the constellation can use, the best of its 300 attribute rows is the candidate object; it exists if that cosine clears 0.23.

In [3]:
frontend, cos_layer, _, _ = load_frontend(FRONTEND, device="cpu")
W = F.normalize(cos_layer.W.data)

def perceive(images):
    x = torch.tensor(images, dtype=torch.float).unsqueeze(1)          # (16, 1, 160, 160)
    with torch.no_grad():
        sims = F.linear(F.normalize(frontend(x)), W).view(16, N_POS, N_PER_POS)
    best, idx = sims[..., :N_ATTR].max(-1)                             # (16, 22) each
    return best.numpy(), idx.numpy()

3. Into the graph¶

The perceived objects are laid into the same structure the model was trained on: 16 panels × 9 slots = 144 nodes, slot k being the k-th position this constellation can use. Empty slots get a learned pad embedding.

4. Reasoning: PyNeuraLogic scores the candidates¶

The checkpoint is copied aside first, because a training job may be writing to that directory. Its template does the message passing and the scoring; torch supplies only the attribute embeddings.

5. Accuracy from pixels on a sample¶

The same five steps over unseen validation puzzles from every constellation, scoring each puzzle from pixels and, for comparison, from the XML labels. The loop also re-checks every puzzle's decoded objects against the GPU pipeline's cache.

In [9]:
N = 20                                       # puzzles per constellation
rows, mismatched_cache = [], 0
t0 = time.time()
for cfg in CONSTELLATIONS:
    cpos = active_positions(cfg)
    hit_pix = hit_xml = seen = n = 0
    for fp in puzzle_files(cfg)[:N]:
        z = np.load(fp)
        mc, ai = perceive(z["image"])
        pix = panels_from_preds(mc, ai, cpos, TAU)
        tru = parse(fp.replace(".npz", ".xml"), cfg)
        r = int(np.where(cache["files"] == os.path.relpath(fp, ROOT))[0][0])
        gpu = panels_from_preds(cache["maxcos"][r], cache["argidx"][r], cpos, TAU)
        mismatched_cache += sum(key(a) != key(b) for a, b in zip(pix, gpu))
        y = int(z["target"])
        with torch.no_grad():
            hit_pix += int(model(*encode_puzzle(pix, cfg)).argmax()) == y
            hit_xml += int(model(*encode_puzzle(tru, cfg)).argmax()) == y
        seen += all(key(a) == key(b) for a, b in zip(pix, tru))
        n += 1
    rows.append((cfg, n, seen, hit_pix, hit_xml))

print(f"{len(CONSTELLATIONS) * N} puzzles in {time.time() - t0:.0f}s\n")
print(f"{'constellation':<40} {'n':>4} {'all 16 seen':>12} {'from pixels':>12} {'from XML':>9}")
tot = [0, 0, 0, 0]
for cfg, n, seen, hp, hx in rows:
    print(f"{cfg:<40} {n:>4} {100 * seen / n:>11.0f}% {100 * hp / n:>11.0f}% {100 * hx / n:>8.0f}%")
    tot = [a + b for a, b in zip(tot, (n, seen, hp, hx))]
n, seen, hp, hx = tot
print("-" * 80)
print(f"{'OVERALL':<40} {n:>4} {100 * seen / n:>11.1f}% {100 * hp / n:>11.1f}% {100 * hx / n:>8.1f}%")
print(f"\npanels whose decoded objects differ from the GPU pipeline: {mismatched_cache}")
assert mismatched_cache == 0

What this shows¶

  • Raw images in, answer out, with the trained ResNet-18 and the trained PyNeuraLogic model in one CPU kernel. Perception is near-perfect on most constellations; the misses are small objects in distribute_nine and in_distribute_four_out_center_single.
  • Pixel accuracy tracks XML accuracy closely: when all 16 panels are perceived correctly, the model's input is identical to the XML version, so the answer is too.
  • The sample is small (20 per constellation), so its percentages move a lot between runs of different puzzles. For the full-split numbers use pixel_pipeline.py (thesis/PYNEURALOGIC_NOTES.md §11): 63.96% from pixels vs 64.00% from XML on the test split, at epoch 62.

Caveats (§11.4): the constellation label comes from the dataset folder, as in the XML pipeline; the frontend was trained on RAVEN, which shares some images with I-RAVEN, inflating perception by under a point where it matters; and the reasoner checkpoint is the live run's current best, so its epoch and scores change as training continues.

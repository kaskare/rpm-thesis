Facet model: generating RPM answers on a per-puzzle object graph¶

The model generates the missing panel (per component: type, size and colour histograms, object count, occupied positions) and then picks the candidate closest to what it generated; candidates are never seen in training. Input: the ground-truth attributes of the context panels. Every puzzle gets its own graph, built by PyNeuraLogic's grounding from the objects that are actually there: no position nodes, no padding.

  • Sections 1–5: I-RAVEN. Weights: experiments/facet_all_w32-64-128_hidden (all 7 constellations, 6000 training puzzles each, widths 32 → 64 → 128, lr 3e-4), the epoch with the best accuracy on val 0–299.
  • Section 6: the same model with copy links, on I-RAVEN-X 3×10, next to the model without them.

Template, facts and evaluation are imported from pynl/bench_hub_grounding.py, so this notebook runs exactly the trained code; pynl/facet_viz.py draws the grounded networks.

2. The graph of this puzzle¶

The picture is read from the network PyNeuraLogic grounds for this puzzle (FV.ground_graph), not drawn by hand. It shows one attribute, type: size and colour have identical copies of this graph, with the same weights. The layers are merged: an object's facets f0, f1, f2 are one node, a panel's pt, pv1, pv2, vF one panel node.

Nodes

  • Facets (circles): one per object and attribute, holding the value as a thermometer code (value v = first v of 10 bits on).
  • Panel nodes (squares): per panel, component and attribute, the average of that component's facets. Number is a fourth attribute with panel nodes only, from the object count.
  • Row nodes rel r1, rel r2: per complete row, "how the attribute changes along the row".
  • ctx: the average of the two row nodes. ans: the answer, from ctx and panels (3,1), (3,2). out: the output.
  • Positions have their own chain of the same shape (panel occupancy → row → answer), not drawn.

Edges

  • facet ↔ facet: same attribute, objects at the same position in another column of the same row (a weight per column pair);
  • facet ↔ its panel node, both ways, in every layer;
  • panel nodes → their row node (a weight per column); row nodes → ctx → ans; panels (3,1), (3,2) → ans → out.
  • Never: between attributes, between rows, or between objects at different positions.

The structural atoms (obj, samepos, row, ...) are hidden: they decide which neurons exist but add nothing to a sum (visible, each added 1.0 to every component and hid the positions from the model).

3. The template, widths 32 → 64 → 128¶

The rules below are the whole model. f0 projects each facet's code to 32, facet layer 1 is 64 wide, layer 2 and everything above it (panel values vF, row relation rel, context ctx, answer ans) 128. Where a layer is wider than the one below, its residual is a learned projection. Attribute and component are variables in every rule, so one set of weights serves type, size, colour and number, and both components.

6. Copy links, on I-RAVEN-X 3×10 (values 0–50)¶

I-RAVEN-X (IBM's generator) has rows of 10 panels, one object per panel and values 0–50. The data is symbolic: there are no images. Without copy links the answer sees rows 1–2 only through the row summary ctx and 128 tanh units, so it misses answers that are one particular context value (Constant, Distribute) and loses precision on large values. Copy links (--copy-links, notes §20) add a direct path: every context panel's own code, scaled to ±4, enters the output logits, multiplied by a gate that the answer node computes, one gate per panel:

gate(p_i, C, A) :- ans(C, A)                       weights per panel p_i
gate(p_i, C, A) :- puzzle(G), pc(p_i, C, A)        bias, starts at -6: the gates start nearly closed
copy(C, A)      :- gate(P, C, A) * pc(P, C, A)     elementwise, summed over the panels
oa(G, A)        :- copy(C, A)                      added to the output logits

Weights: experiments/facet_iravenx_n10_m50_copy (60 epochs, picked epoch 55) and, without copy links, experiments/facet_iravenx_n10_m50 (picked epoch 35). Both trained on puzzles 0–5999 with the epoch picked on 6000–6299; below are the first 300 unseen puzzles (6300+).

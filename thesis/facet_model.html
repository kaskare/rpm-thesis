Facet model: generating I-RAVEN answers on a per-puzzle object graph¶

The model generates the missing panel (per component: type, size and colour histograms, object count, occupied positions) and then picks the candidate closest to what it generated; candidates are never seen in training. Input: the ground-truth XML attributes of the 8 context panels. Every puzzle gets its own graph, built by PyNeuraLogic's grounding from the objects that are actually there: no position nodes, no padding.

Weights: experiments/facet_all_w32-64-128_hidden (all 7 constellations, 6000 training puzzles each, widths 32 → 64 → 128, lr 3e-4), the epoch with the best accuracy on val 0–299. Template, facts and evaluation are imported from pynl/bench_hub_grounding.py, so this notebook runs exactly the trained code.

2. The graph of this puzzle¶

Nodes

  • Facets: each object becomes 3 nodes, its type, its size and its colour (thermometer codes: value v = first v of 10 bits on).
  • Panel nodes: per panel, component and attribute (type, size, colour, number): a summary of that component's objects.
  • Row nodes: per complete row (1 and 2), component and attribute: "how the attribute changes along the row".
  • Answer nodes: per component and attribute. Positions have their own chain (panel occupancy → row → answer).

Edges

  • facet ↔ facet: same attribute, objects at the same position in another column of the same row (weight per column pair);
  • facet ↔ its panel node (both ways); panel nodes → row node (weight per column); rows 1–2 and panels (3,1), (3,2) → answer.
  • Never: between attributes, between rows, or between objects at different positions.

All of this is written once, as rules; grounding instantiates it for the objects present. The structural atoms (obj, samepos, row, ...) are hidden: they decide which neurons exist but add nothing to a sum (visible, each added 1.0 to every component and hid the positions from the model). Below: the objects of this puzzle, each drawn as its three facets, and the same-position edges.

def draw_graph(panels, s=210, g=26):
    img = Image.new("RGB", (3 * s + 4 * g, 3 * s + 4 * g + 24), (255, 255, 255)); d = ImageDraw.Draw(img)
    xy = lambda p, o: (g + (p % 3) * (s + g) + o["cx"] * s, g + (p // 3) * (s + g) + o["cy"] * s)
    for p in range(9):
        x0, y0 = g + (p % 3) * (s + g), g + (p // 3) * (s + g)
        d.rectangle([x0, y0, x0 + s, y0 + s], outline=(180, 178, 169), width=1)
        d.text((x0 + 4, y0 + 3), "?" if p == 8 else f"({p // 3 + 1},{p % 3 + 1})", fill=(136, 135, 128))
    n_edges = 0
    for row in ((0, 1, 2), (3, 4, 5), (6, 7)):
        for a in row:
            for b in row:
                if a < b:
                    for oa in panels[a]:
                        for ob in panels[b]:
                            if oa["pos"] == ob["pos"]:
                                d.line([xy(a, oa), xy(b, ob)], fill=(175, 169, 236), width=2); n_edges += 1
    colours = {"type": (83, 74, 183), "size": (29, 158, 117), "color": (216, 90, 48)}
    for p in range(8):
        for o in panels[p]:
            x, y = xy(p, o)
            for j, a in enumerate(B.FACET_ATTRS):
                cx = x + (j - 1) * 13
                d.ellipse([cx - 6, y - 6, cx + 6, y + 6], fill=colours[a], outline=(255, 255, 255))
    lx = g
    for a, c in colours.items():
        d.ellipse([lx, 3 * s + 3 * g + 10, lx + 10, 3 * s + 3 * g + 20], fill=c); d.text((lx + 14, 3 * s + 3 * g + 9), a, fill=(60, 64, 72)); lx += 70
    d.line([lx, 3 * s + 3 * g + 15, lx + 26, 3 * s + 3 * g + 15], fill=(175, 169, 236), width=2)
    d.text((lx + 32, 3 * s + 3 * g + 9), "same position, another column", fill=(60, 64, 72))
    display(img)
    return n_edges

3. The template, widths 32 → 64 → 128¶

The rules below are the whole model. f0 projects each facet's code to 32, facet layer 1 is 64 wide, layer 2 and everything above it (panel values vF, row relation rel, context ctx, answer ans) 128. Where a layer is wider than the one below, its residual is a learned projection. Attribute and component are variables in every rule, so one set of weights serves type, size, colour and number, and both components.

4. Generating the answer¶

Every puzzle of val 300–399 in all seven constellations is grounded in one go (PyNeuraLogic builds a model's dataset once); our puzzle is among them. One sample per component of the missing panel.

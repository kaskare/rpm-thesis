Symmetries as inductive bias: the notebook behind the briefing¶

This notebook goes with the briefing page Symmetry Thesis Briefing and follows its eight sections. Every table is read from the run directories (best.json, history.json, job logs) or computed here, so each number can be traced to a file. Two notebooks show the models in detail: notebooks/facet_model.ipynb (one puzzle through the facet model) and notebooks/value_axis.ipynb (one puzzle through the value axis).

Cells are matched % (exact %) on unseen puzzles (I-RAVEN val 300+, I-RAVEN-X 6300+), with the epoch picked on the selection puzzles. Matched: the candidate closest to the generated answer is right (ties wrong, chance 12.5%). Exact: the generated panel equals the answer. One seed unless a cell says otherwise.

def facet(d):
    """A facet-model run: unseen matched % and exact % (its best.json stores counts)."""
    u = json.load(open(f"{E}/{d}/best.json"))["unseen"]
    n = sum(t for _, t in u["per_constellation"].values())
    return 100 * u["matched"] / n, 100 * u["exact"] / n

def torch_run(d, seeds=(0,), key=None):
    """A torch run: unseen matched % and exact %, the mean over seeds; key picks another record (a transform)."""
    rs = [json.load(open(f"{RUNS}/{d}_s{s}/best.json")) for s in seeds]
    rs = [r["transforms"][key] if key else r["best"]["unseen"] for r in rs]
    return np.mean([100 * r["matched"] for r in rs]), np.mean([100 * r["exact"] for r in rs])

def rule_exact(rec, rule):
    h, t = rec["exact_per_rule"][rule]
    return 100 * h / t

def cell(me):
    return "–" if me is None else f"{me[0]:.1f} ({me[1]:.1f})"

def table(header, rows):

def chart(series, title, xticks, xmax, ylabel="matched %", w=680, h=300):
    """Lines on one 0-100 axis. series: [(name, [(x, y), ...])]; xticks: [(x, label)]."""
    L, Rm, T, Bm = 48, 200, 34, 40
    pw, ph = w - L - Rm, h - T - Bm
    X, Y = (lambda x: L + pw * x / xmax), (lambda v: T + ph * (1 - v / 100))
    s = [f'<svg xmlns="http://www.w3.org/2000/svg" width="{w}" height="{h}" viewBox="0 0 {w} {h}" '
         f'font-family="Helvetica, Arial, sans-serif" font-size="12"><rect width="{w}" height="{h}" fill="white"/>',
         f'<text x="{L}" y="18" font-size="13" font-weight="bold" fill="#1a202c">{title}</text>']
    for g in range(0, 101, 20):
        s += [f'<line x1="{L}" x2="{L + pw}" y1="{Y(g):.1f}" y2="{Y(g):.1f}" stroke="#e2e8f0"/>',
              f'<text x="{L - 6}" y="{Y(g) + 4:.1f}" text-anchor="end" fill="#4a5568">{g}</text>']
    s += [f'<text x="{X(x):.1f}" y="{T + ph + 18}" text-anchor="middle" fill="#4a5568">{t}</text>' for x, t in xticks]
    s.append(f'<text x="13" y="{T + ph / 2:.0f}" transform="rotate(-90 13 {T + ph / 2:.0f})" text-anchor="middle" '
             f'fill="#4a5568">{ylabel}</text>')
    ends = []
    for k, (name, pts) in enumerate(series):
        c, pts = PALETTE[k % len(PALETTE)], [(X(x), Y(y)) for x, y in pts]
        s.append(f'<polyline fill="none" stroke="{c}" stroke-width="2" points="{" ".join(f"{x:.1f},{y:.1f}" for x, y in pts)}"/>')
        s += [f'<circle cx="{x:.1f}" cy="{y:.1f}" r="2.5" fill="{c}"/>' for x, y in pts] if len(pts) < 40 else []
        ends.append([pts[-1][1], name, c])
    ends.sort()
    for j in range(1, len(ends)):                       # end labels at least 14 px apart
        ends[j][0] = max(ends[j][0], ends[j - 1][0] + 14)
    s += [f'<text x="{L + pw + 10}" y="{y + 4:.1f}" fill="{c}">{name}</text>' for y, name, c in ends]
    return SVG("".join(s) + "</svg>")

1. The facet model¶

The facet model generates the missing panel and only then picks the closest candidate; it never sees the candidates, not even in training. One node per (object, attribute), values as thermometer codes, a graph grounded for every puzzle. The template names no object, row, component or attribute, so renaming them cannot change any output: that is how its symmetries are built in (notes §21.2).

The theorem, checked here. Each transformation below is applied to one unseen puzzle per I-RAVEN layout, and the largest change of any output is reported, over two draws of random weights. Zero (to rounding) means the symmetry is built in. Per-panel copy gates name the panels, so rows 1 ↔ 2 is no longer built in; content gates restore it. Columns 1 ↔ 2 is a control that no model has. The positions channel names its slots, so the mirror is built in for attributes only. The last column runs the trained checkpoint and counts the puzzles whose chosen candidate changes.

The recursive version: the row fold (notes §25)¶

The row fold reads a row with a running state that one recursive rule moves along it, a panel at a time (--columns fold). Below: its rules as the template prints them, its weights at three row lengths, and its symmetries on random weights, on five unseen I-RAVEN-X 3×10 puzzles. One transition serves every step, so the template names no column and its weights do not depend on the row length. Being a fold, it reads the row in order, so the middle columns are not interchangeable.

Recursion can transfer: a toy. The same construct at its smallest: a linear two-rule fold, trained on rows of 3–5 digits to output their sum, then scored on rows of 3, 5, 10 and 20. It learns a transition weight of 1, so the state means the same after any number of steps. The facet fold has tanh steps and saw rows of 10 only; nothing asked its state to mean the same after 4 steps as after 9. Mixed-length training of the facet fold is the open test.

from neuralogic.core import Model, R, V, Transformation, Metadata
from neuralogic.dataset import Dataset, Sample
toy = Model()
toy += (R.acc(V.P) <= (R.hidden.first(V.P), R.x(V.P)[1, 1]))                           # start: the first digit
toy += (R.acc(V.Q) <= (R.hidden.next(V.P, V.Q), R.acc(V.P)[1, 1], R.x(V.Q)[1, 1]))      # one step: state + next digit
toy += (R.out <= (R.hidden.last(V.P), R.acc(V.P)[1, 1]))                                # read the state at the end
toy += (R.acc / 1) | Metadata(transformation=Transformation.IDENTITY)
toy += (R.out / 0) | Metadata(transformation=Transformation.IDENTITY)
toy.build(Settings(optimizer=Adam(lr=0.01), error_function=MSE(), iso_value_compression=False))

rng = np.random.default_rng(0)
def digit_rows(lengths):
    out = []
    for n in lengths:
        xs = rng.integers(0, 10, n)
        facts = [R.x(f"p{i}")[float(v) / 10] for i, v in enumerate(xs)] + [R.hidden.first("p0"), R.hidden.last(f"p{n - 1}")]
        out.append((Sample(R.out[float(xs.sum()) / 10], facts + [R.hidden.next(f"p{i}", f"p{i + 1}") for i in range(n - 1)]),
                    xs.sum()))
    return out

toy.train(toy.build_dataset(Dataset([s for s, _ in digit_rows(rng.integers(3, 6, 300))])), epochs=100)
rows = []
for n in (3, 5, 10, 20):
    te = digit_rows([n] * 200)
    pred = 10 * np.array(toy.test(toy.build_dataset(Dataset([s for s, _ in te]))), dtype=float).flatten()
    rows.append([n, f"0–{9 * n}", f"{np.mean(np.abs(pred - [y for _, y in te])):.3f}"])

def strongest(ds):
    groups = {}
    for d in glob.glob(f"{RUNS}/{ds}_mlp*") + glob.glob(f"{RUNS}/{ds}_gnn*"):
        name = re.sub(r"_s\d$", "", os.path.basename(d))
        if not re.search(r"_n\d+$|holdPS|noUD|_rows|_de0", name):
            groups.setdefault(name, []).append(json.load(open(f"{d}/best.json"))["best"])
    best = max(groups, key=lambda k: np.mean([b["sel"]["matched"] for b in groups[k]]))
    g = groups[best]
    return np.mean([100 * b["unseen"]["matched"] for b in g]), np.mean([100 * b["unseen"]["exact"] for b in g]), best

4. Symmetries of the datasets¶

Which rule instances survive a transformation, counted on the first 1000 puzzles of each I-RAVEN-X file (pynl/dataset_symmetry_check.py). A transformation that keeps 100% of a rule is a task symmetry for it; whether it is also a data symmetry depends on the generator's statistics. On 3×10, rows 1 ↔ 2 breaks Distribute as generated: its rows are row 1 shifted by a constant step, and after the swap no step fits ("any step" allows a different one), so the generator never produces the swapped puzzle. The answer, the one value row 3 lacks, stays right, so the swap is still a task symmetry.

6. Why Arithmetic is hard¶

A shift breaks a sum. A rule c = p·a + q·b survives "every panel + s" exactly when p + q = 1: the shifted answer is c + (p + q)s, and it should be c + s.

What a shift-equivariant model can do. If f(a + s, b + s) = f(a, b) + s, then f(a, b) = b + h(b − a): the model can only take a step from b, chosen from the first step b − a. Count the rows on values 0–50 (a, b ≥ 1): how many first steps there are, and how many rows such a model can get right at best. For midpoint the needed step is fixed by the first step, so the table collapses.

Why a GNN can still learn a sum. In thermometer codes (value v = the first v bits on) unit i of the answer is on exactly when a + b > i, and a + b is the number of ones in the two codes together. So one linear layer with every weight 1 and a threshold per unit computes the sum. The same holds for plus and minus over nine operands, with weights +1 and −1.

7. The value-axis model¶

Values are constants on an axis, and a convolution runs along it: one learned code per offset −2 … +2, and scoring layers with the same weights at every value. It is given plus, value counts per row and the offsets, and learns which rule holds. Exact per rule is the argmax of its value distribution (best.json per_rule). The model in detail: notebooks/value_axis.ipynb.
